📝 To-Do List Web Application
A stylish and interactive To-Do List web app built with HTML, CSS, and JavaScript. This application allows users to add, edit, delete, and mark tasks as complete, along with setting reminders and displaying a real-time clock.

🚀 Features
✅ Add and delete tasks

✏️ Edit tasks inline

⏰ Set reminders with time-based notifications

✔️ Mark tasks as complete/incomplete

💾 Persist tasks using localStorage

🕒 Real-time digital clock

🎨 Modern responsive UI with animations

📁 File Structure
File	Description
index.html	Main HTML page that structures the application UI.
style.css	Stylesheet for the UI, including layout, animations, and responsiveness.
script.js	JavaScript file that handles all dynamic interactions and logic.

🛠️ How to Use
Clone or Download the Repository
Download the files and place them in the same directory.

Open index.html in a browser
Double-click or right-click and open in any modern browser.

Start Using

Type a task and optionally select a reminder time.

Click "Add Task" to insert it into your list.

Click on a task to mark it as completed.

Use the 🖉 (edit) and 🗑️ (delete) icons to modify or remove tasks.

You'll get a browser alert when a task’s reminder time is reached.

📌 Notes
Reminders use the browser’s alert() and check every minute.

All data is saved locally in your browser (via localStorage).

Tasks are lost only if the browser's local storage is cleared.
